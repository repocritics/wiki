# koala73/worldmonitor

A real-time global intelligence dashboard — AI-powered news aggregation, geopolitical monitoring, and infrastructure tracking in one situational-awareness interface.

## What it is

A TypeScript-based dashboard that aggregates global news, geopolitical events, and infrastructure-monitoring data into a unified "situational awareness" view. Topic-tagged with `palantir` (the company name is being used as a category descriptor, not affiliation) and `osint`. License is `NOASSERTION` — verify before commercial use.

## Key features

- AI-aggregated news from many sources.
- Geopolitical event tracking.
- Infrastructure status monitoring.
- Real-time dashboard UI.
- Hosted at worldmonitor.app.

## Tech stack

- TypeScript primary.

## When to reach for it

- You're a researcher or analyst who wants a unified live dashboard.
- You're evaluating the OSS OSINT / situational-awareness tooling space.

## When *not* to reach for it

- You want vendor-stable data feeds with SLAs.
- You're allergic to non-OSI licenses — `NOASSERTION` carries restrictions; verify.
- You need source-attributed news — AI-aggregated feeds need fact-check verification.
