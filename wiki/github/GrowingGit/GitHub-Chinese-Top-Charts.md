# GrowingGit/GitHub-Chinese-Top-Charts

A Chinese-language GitHub trending tracker — language-segmented top-projects rankings updated periodically with "software" + "resources" sub-charts.

## What it is

A Chinese-curated leaderboard of trending GitHub projects, sliced by programming language, with two sub-charts per language: software (libraries, frameworks, tools) and resources (books, tutorials, awesome-lists). Aimed at Chinese-speaking developers who want a curated, frequently-refreshed view of "what's hot" without scrolling GitHub Trending themselves. Chart updates were monthly during active development; the project entered a slower cadence in late 2024.

## Key features

- Per-language top-100 lists (JavaScript, Python, Java, Go, Rust, C++, etc.).
- Software / resources split per language — separates working tools from learning materials.
- Chinese-language curation with bilingual descriptions where useful.
- Monthly update cadence during the project's active years.
- Java is the language tag — likely for the chart-generation scripts.

## Tech stack

- Markdown content as the published charts.
- Java for chart-generation scripts.

## When to reach for it

- You're a Chinese-speaking developer who wants periodic top-projects curation in your language.
- You're tracking how Chinese developer interest has shifted over time — the historical charts are a primary source.
- You're studying alternative GitHub-Trending curation methodologies.

## When *not* to reach for it

- You want real-time trending — the cadence is monthly at best, and updates slowed in 2024.
- You're not comfortable reading Chinese.
- You want a license-clean redistribution — SPDX `NOASSERTION`; verify LICENSE before vendoring.

## Maturity signal

108k stars, 14k forks, last push October 2024 — entered a dormant phase. Open-issues count of 193 is moderate; most are chart-update requests. The high watcher count (2,636) reflects Chinese developers using this as their canonical periodic-curation source during the project's active years.

## Alternatives

- GitHub Trending — use for real-time English-language trending.
- `521xueweihan/HelloGitHub` — Chinese-language monthly OSS digest with editorial curation rather than algorithmic charting.
- `ruanyf/weekly` — Chinese-language tech weekly with broader scope.

## Notes

The dormancy is the most important non-obvious fact — the charts here are historical snapshots, not live data, as of mid-2024. License absence is the typical gotcha for redistribution. For ongoing Chinese-language curation, the more-active alternatives (HelloGitHub, weekly) are the right pointers; this repo is best treated as a stable archive.
