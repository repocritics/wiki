# type-challenges/type-challenges

Type Challenges — a collection of TypeScript type-system puzzles. Train your skill at TS's compile-time type system through progressively harder challenges.

## What it is

A TypeScript-puzzles collection ranging from "warm" (write a `MyPick<T, K>` equivalent) to "extreme" (parse SQL at the type level, implement a regex engine in types). Each challenge has a description, starter code, and a test file. Authored by Anthony Fu + community contributors. Used as TypeScript skill-up material by many engineers.

## Key features

- 5 difficulty tiers: warm, easy, medium, hard, extreme.
- Each challenge has tests verifying the type implementation.
- Multi-language translations.
- Online playground (typehero.dev and similar) for solving in browser.
- Apache 2.0 licensed.

## Tech stack

- TypeScript primary.

## When to reach for it

- You're leveling up TypeScript type-system fluency.
- You're prepping for senior TS interviews where type-system depth comes up.

## When *not* to reach for it

- You're new to TypeScript — start with the official handbook first.
- You want practical patterns — these are puzzles, not idiomatic library code.
