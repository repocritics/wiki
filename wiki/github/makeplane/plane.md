# makeplane/plane

An open-source Jira / Linear / Monday / ClickUp alternative — modern project management with tasks, sprints, docs, and triage.

## What it is

A TypeScript + Django + Python project-management platform aimed at the segment dominated by Jira and Linear. Issue tracking, kanban boards, sprint planning, gantt charts, docs, triage workflows. Self-hostable via Docker; commercial cloud at plane.so. AGPL-3.0 licensed.

## Key features

- Issues, kanban, sprints (cycles), modules, gantt views.
- Docs (Notion-style) embedded in projects.
- Triage workflow for inbound issues.
- Custom views, filters, properties.
- Self-host (Docker, Kubernetes) or use Plane Cloud.
- AGPL-3.0 licensed.

## Tech stack

- TypeScript primary (Next.js frontend).
- Python (Django) on the backend.
- PostgreSQL + Redis.
- Docker Compose deployment.

## When to reach for it

- You want a self-hostable Jira / Linear alternative.
- You're privacy-sensitive about project-management data.

## When *not* to reach for it

- You're allergic to AGPL — verify implications for SaaS hosting.
- You want vendor-supported with extensive integrations — Jira / Linear have larger ecosystems.
