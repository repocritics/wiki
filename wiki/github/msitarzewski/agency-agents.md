# msitarzewski/agency-agents

A collection of pre-built AI "agency" agents — specialized experts (frontend wizards, Reddit ninjas, reality checkers) with personalities, processes, and deliverables. Shell-script-based.

## What it is

A TypeScript / Shell catalog of role-based AI agents pitched as a "complete AI agency" — frontend wizard, Reddit community ninja, whimsy injector, reality checker, and others. Each agent is a system-prompted persona + workflow recipe. MIT-licensed.

## Key features

- Pre-built role-based agents covering "agency" workflows.
- Personality + process + deliverable definitions per agent.
- Shell-script substrate.
- MIT-licensed.

## Tech stack

- Shell primary.

## When to reach for it

- You're a Claude Code / Cursor user and want a curated catalog of role-based personas.

## When *not* to reach for it
