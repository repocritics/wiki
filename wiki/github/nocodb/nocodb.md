# nocodb/nocodb

NocoDB — a free, self-hostable Airtable alternative. Turns any SQL database into a spreadsheet-style UI with automatic REST + Swagger APIs.

## What it is

A TypeScript app that connects to your SQL database (Postgres, MySQL, SQLite, MariaDB, MSSQL) and exposes the tables as Airtable-style views: grid, kanban, gallery, calendar, form. Automatic REST + Swagger APIs for each table. Self-hostable; commercial cloud available. Aimed at teams that want Airtable's UX without Airtable's pricing or lock-in. License `NOASSERTION` — verify.

## Key features

- Connect to existing SQL databases (Postgres, MySQL, SQLite, MariaDB, MSSQL).
- Spreadsheet, kanban, gallery, calendar, form views.
- Automatic REST + Swagger APIs.
- Webhooks, formulas, lookup fields, rollups.
- Multi-user with permissions.
- Self-host via Docker; commercial cloud available.

## Tech stack

- TypeScript primary.
- Node.js / NestJS backend.
- Vue.js frontend.
- Distributed via Docker.

## When to reach for it

- You want Airtable's UX but with your own SQL database and self-hosting.
- You need automatic REST APIs over an existing database.

## When *not* to reach for it

- You're allergic to non-OSI licenses — `NOASSERTION` carries restrictions; verify.
- You want simple spreadsheets — Airtable itself or Google Sheets are friendlier.
