# d3/d3

D3 — data-driven documents. The canonical JavaScript library for building custom data visualizations with SVG, Canvas, and HTML.

## What it is

A modular JavaScript library that gives developers low-level primitives for binding data to DOM elements, computing layouts, and animating transitions. D3 doesn't ship "charts" — it ships the building blocks (scales, axes, generators, hierarchies, force simulations, geographic projections, color spaces, time formats) that every higher-level charting library is built on top of. The result: D3 is the right tool when you need a visualization that doesn't exist yet; chart libraries are the right tool when one does.

## Key features

- Modular core: `d3-scale`, `d3-axis`, `d3-shape`, `d3-hierarchy`, `d3-force`, `d3-geo`, etc., each importable independently.
- SVG, Canvas, and HTML targets — the same data + layout pipeline drives any of the three.
- Enter / update / exit pattern for animated, data-bound DOM updates.
- Force simulation for network graphs and physics-driven layouts.
- Geographic projections, contour generation, hexbin layouts.
- ISC-licensed.

## Tech stack

- Shell at the language tag (build scripts); the library itself is modern JavaScript distributed as ES modules.
- npm packages: `d3` (the bundled umbrella) and each `d3-*` sub-package individually.
- Tree-shakable — importing only what you need keeps bundle size manageable.

## When to reach for it

- You're building a bespoke visualization where existing chart libraries don't fit.
- You're teaching data visualization — D3 is the canonical learning vehicle.
- You're working with geographic data, network graphs, or hierarchical layouts where D3's primitives are best-in-class.

## When *not* to reach for it

- You want a one-line API for standard charts (bar, line, area, pie) — Chart.js, Recharts, Apache ECharts, Plotly are closer-fit.
- You want React-component integration without writing your own bridge — Visx, Nivo, or Recharts wrap D3 for React.
- You want zero-config dashboards — Observable Framework or Tableau-style tools fit better.

## Maturity signal

113k stars, 23k forks, ISC, last push 2026-05-28 — actively maintained on a deliberate cadence (D3 prioritizes stability over feature churn). 15-year-old project — among the oldest mainstream JS libraries still in active development. Open-issues count of 20 is unusually low and signals tight maintainer focus.

## Alternatives

- `d3/d3` higher-level wrappers: Observable Plot — use when you want D3-quality output with chart-library ergonomics.
- Chart.js, Apache ECharts, Plotly.js — use for standard chart types.
- Visx, Nivo, Recharts — use for React-component-flavored D3.
- Vega / Vega-Lite — use when you want declarative-grammar-based visualization.

## Notes

The "D3 is hard" reputation is partially earned (the enter/update/exit pattern has a steep learning curve) and partially obsolete (modern D3 is much more module-importable than D3v3 ever was). The ISC license is the most permissive among major visualization libraries. Observable Plot, by the same author, is the modern recommendation when you don't need bespoke layouts — it sits on top of D3 with chart-library ergonomics.
