# marktext/marktext

A simple, elegant Markdown editor for Linux, macOS, and Windows — Electron-based, focuses on writing UX over feature-checklist.

## What it is

An Electron + Vue desktop Markdown editor that emphasizes a writing-friendly interface: typewriter mode, focus mode, dark mode, source view ↔ live preview toggle, LaTeX math, mermaid diagrams. Designed for writers and developers who want a polished local Markdown UX without Notion-style cloud lock-in.

## Key features

- Multiple display modes: source, live preview, typewriter, focus.
- LaTeX math (KaTeX) + mermaid diagrams inline.
- Dark mode + themes.
- File-tree sidebar.
- Multi-tab editing.
- Cross-platform (Windows, macOS, Linux).
- MIT-licensed.

## Tech stack

- TypeScript primary; Vue on the renderer.
- Electron for cross-platform packaging.

## When to reach for it

- You write Markdown a lot and want a polished local editor.
- You want LaTeX + mermaid without a build pipeline.

## When *not* to reach for it

- You want collaborative real-time editing — MarkText is single-user local.
- You want sync — handle that yourself via Git / cloud storage.

## Maturity signal

57k stars, 4k forks, MIT, actively maintained. Open-issues count of 1,063 reflects the breadth of platform-specific quirks.

## Alternatives

- Obsidian (closed source, free) — Markdown notes with sync + plugins.
- Typora — commercial Markdown editor.
- Logseq — block-based local-first.
