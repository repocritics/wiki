# ant-design/ant-design

An enterprise-class UI design language and React component library from Ant Group — dominant in the Chinese enterprise React ecosystem and widely used globally.

## What it is

A React UI library with a comprehensive component set (60+ components: forms, tables, navigation, charts, layouts) plus an associated design language (typography, color, motion guidelines). Ships with extensive customization tokens. Used heavily for admin dashboards, enterprise apps, and SaaS back-offices.

## Key features

- 60+ React components covering forms, tables (with virtualization), navigation, layouts.
- Design tokens for theming — Ant Design 5 introduced CSS-in-JS with extensive customization.
- Internationalization for ~50 locales.
- Pro/Plus paid variants and templates available.
- Companion libraries: AntV (data visualization), Ant Design Mobile, Ant Design Charts.
- MIT-licensed.

## Tech stack

- TypeScript primary.
- React on the consumer side.
- CSS-in-JS (Ant Design 5+) for theming.
- Distributed via npm `antd`.

## When to reach for it

- You're building admin dashboards or enterprise SaaS in React.
- You're shipping to a Chinese-market audience — Ant Design has the strongest Chinese-locale support.
- You need rich tables, complex forms, or advanced layout primitives.

## When *not* to reach for it

- You want consumer-facing, brand-distinctive UI — Ant Design's aesthetic is enterprise-flavored.
- Bundle size matters — Ant Design is heavy; lighter alternatives ship faster.
- You're shadcn-ui-curious — you'd lose the npm-managed upgrade path.

## Maturity signal

98k stars, 55k forks, MIT, actively maintained. 10+ years. Open-issues count of 1,340 reflects the breadth. Ant Group's commercial backing keeps the project well-funded.

## Alternatives

- `mui/material-ui`, `mantine/mantine`, `chakra-ui/chakra-ui` — Western-flavored alternatives.
- `shadcn-ui/ui` — copy-paste model; very different distribution philosophy.
- `chakra-ui/chakra-ui` — use for accessibility-first, smaller surface.
